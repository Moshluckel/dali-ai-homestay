# 大理民宿 AI 在地管家 — V0

这是一个**可以本地直接跑起来的销售演示原型**，不是PPT。

它包含：

- 住客扫码 H5
- 民宿老板后台
- SQLite 数据库
- 民宿结构化 FAQ
- 大理本地 POI / 体验推荐
- 高风险问题自动转人工
- DeepSeek API 可选接入
- 高德步行路线 API 可选接入
- 基础事件埋点和使用数据

## 1. 这个 V0 要验证什么

不是验证“AI能不能聊天”，而是验证 4 个问题：

1. 住客愿不愿意扫码使用？
2. 高频问题能否由系统准确解决？
3. 老板是否感知到前台重复劳动减少？
4. 本地体验推荐是否能产生点击/咨询/订单意向？

**第一阶段不要继续加 PMS、门锁、小程序、OTA 自动回复。**

---

## 2. 本地运行

建议 Python 3.11+。

```bash
cd dali_ai_homestay_v0
python -m venv .venv

# macOS / Linux
source .venv/bin/activate

# Windows
# .venv\Scripts\activate

pip install -r requirements.txt

# 第一次运行会自动创建并初始化 SQLite
uvicorn app:app --reload
```

浏览器打开：

- 住客端：`http://127.0.0.1:8000/guest`
- 老板后台：`http://127.0.0.1:8000/admin`
- API 文档：`http://127.0.0.1:8000/docs`

---

## 3. 可选：接入真实 DeepSeek

复制：

```bash
cp .env.example .env
```

然后设置系统环境变量，或直接在运行终端中导出：

```bash
export DEEPSEEK_API_KEY="你的key"
export DEEPSEEK_MODEL="deepseek-v4-flash"
```

没有 API Key 时，V0 仍然可以用本地规则和数据库完成演示。

> 正式产品中不要把 API Key 写进前端。

---

## 4. 可选：接入高德路线

```bash
export AMAP_WEB_KEY="你的高德Web服务Key"
```

当用户问“怎么去 / 多远 / 步行多久”且目的地能匹配到本地 POI 时，
后端会尝试查询真实步行路线；失败则自动退回本地数据。

## 6. 产品逻辑

```text
住客提问
   ↓
高风险/经济承诺类？
   ├─ 是 → 立即转人工
   ↓ 否
结构化民宿事实能回答？
   ├─ 是 → 数据库事实回答
   ↓ 否
属于本地吃喝玩乐/体验？
   ├─ 是 → 可信 POI / Experience 库
   ↓ 否
配置了 LLM？
   ├─ 是 → 带事实上下文调用 LLM
   ↓ 否
安全兜底 → 建议转人工
```

AI **不能决定**：

- 退款/赔偿
- 免费升级
- 延迟退房费用减免
- 医疗和安全事故处置
- 遗失贵重物品责任
- 房费争议
- 代表民宿做经济承诺
